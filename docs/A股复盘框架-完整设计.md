# A股复盘框架 · 完整设计

> 目标：搭建一个能**随时评估当下整体环境、定位其在历史上的位置（走势+大量指标）**，并**基于历史每轮牛熊构建量化评估体系**的应用。
> 核心研究框架：**叙事经济学**（用于识别 A 股整体起涨 与 板块/ETF 起涨）。
> 制图：**ADV 工具**（`?chart=` 链接）。数据：本地数据资产 + akshare + datahubco API。

---

## 0. 一句话定位

把"现在市场走到哪一步了"这件事，从**主观感觉**变成**可复现的量化判断**：
**周期位置（牛/熊/震荡 + 三阶段）→ 环境温度（四层指标分位打分）→ 主线与叙事（谁是主线、叙事走到哪一步）→ 操作含义（左侧/右侧/止盈/规避）。**

│   ↓                                                        │

五层对应五大研究模块，每个模块有独立指标与判定规则，最终合成一张**「当下环境评分卡」**。

|---|---|---|---|

| L5 择时信号 | 短期该不该动、方向 | 广发金工「黄金分割/融资风险」+ 广发「资金面」 | 技术指标 + 资金/情绪面 |

## 2. 牛熊周期划分与「历史位置」定位（L2）

### 2.1 规范周期划分（研报口径，作为"教科书"基线）

| 轮次 | 牛市起点 | 牛市高点 | 熊市低点 | 上证最大涨幅 | 熊市跌幅 | 类型 | 驱动 / 主线 |
|---|---|---|---|---|---|---|---|
| ① 05–08 | 2005/6/6 (998) | 2007/10/16 (6124) | 2008/10/28 (1664) | +513% | -73% | 全面牛 | 股改+强经济；周期+大金融 |
| ② 09–12 | 2008/10/28 (1664) | 2009/8/4 (3478) | 2012/12/4 (1949) | +109% | -44% | 反弹牛 | 四万亿；基建→消费→科技 |
| ③ 13–15 | 2012/12/4 或 2013/6/25 | 2015/6/12 (5178) | 2016/1/27 (2638) | +180% | -45% | 全面牛 | 移动互联网+杠杆；TMT |
| ④ 16–18 | 2016/1/27 (2638) | 2018/1/26 (3587) | 2019/1/4 (2440) | +36% | -32% | 结构牛 | 供给侧+北向；价值/消费龙头 |
| ⑤ 19–21 | 2019/1/4 (2440) | 2021/2 (3731) | 2022/4/27 (2863) | +53% | -20%+ | 结构牛 | 新能源+核心资产 |
| ⑥ 24–今 | 2024/2/5 (2635) | 进行中 | — | 进行中 | — | 待定 | 924 政策+AI/算力 |

> 数据依据：`A股数据/应用数据/index_daily.csv`（上证 1990-12-19 至 2026-11-10，8,760 个交易日）。早期（1991–1996）波动剧烈、无稳定周期结构，量化框架**以 2005 年为起点**做规范划分。

### 2.2 牛熊二分：全面牛 vs 结构牛（光大口径）

| 判定 | 阈值 |
|---|---|
| 全面牛 | 上证区间涨幅 **≥100%** 且 涨幅>100% 行业占比 **≥85%** |
| 结构牛 | 上证区间涨幅 **<100%** 且 该占比 **<35%** |
| 资金主体 | 全面牛=个人/杠杆资金；结构牛=机构（北向/偏股基金） |

**可编码辅助判据**：全面牛日均涨幅 0.34%/0.21% vs 结构牛 0.06%；全面牛日振幅峰值 >4%；全行业连续四季 ROE(TTM) 改善占比峰值 >50% = 全面牛、始终 <40% = 结构牛。

### 2.3 牛市三阶段（孕育/爆发/泡沫）→ 映射「初期/中期/后期」

| 阶段 | 特征 | 识别信号 |
|---|---|---|
| 孕育期（起点/初期） | 流动性先行、盈利未起 | 降准降息/社融-M2 拐点；盈利触底回升；估值低位+风险溢价≈均值+1σ |
| 爆发期（中期） | 盈利与风险偏好共振 | 中美流动性共振；增量资金正反馈；主线 ROE 上行+成交占比放大 |
| 泡沫期（后期/顶点） | 估值极端、情绪过热 | 全A PE 56–57 倍；换手/融资买入占比/涨停占比高位；利空免疫 |

### 2.4 「当下在历史哪个位置」的量化定位法（核心算法）

**输入**：任一交易日 T，输出该日所处的周期阶段标签 + 各指标历史分位。

1. **周期标签**：对指数日线做峰谷分段（阈值 20% 回撤 + 最小持续期过滤），与 2.1 规范划分对齐校验；输出"牛/熊/震荡 + 第几轮"。
2. **阶段标签**：用估值分位 + 成交趋势 + 盈利增速 + 均线斜率联合切分"孕育/爆发/泡沫"。
3. **历史分位**：对每项指标（PE、PB、换手率、风险溢价、融资买入占比、成交额占比…）计算其当前值在**过去 N 年（默认 10 年）滚动窗口**中的分位（0–100%），输出"温度计"。
4. **合成定位**：分位 + 阶段标签 → 输出一句人话："当前处于第 6 轮牛市的『爆发期后段』，全A PE 处于近 10 年 87% 分位，风险溢价处于 12% 分位。"

## 4. 叙事经济学研究框架（核心，L4）

### 4.0 中心命题（全文的灵魂）

> **超额收益只在「叙事发生变化的一瞬间」完成，与业绩增速无关；兑现叙事不产生任何超额收益（无论增速多高）。**
> 正确拆分：股价涨幅 = 必要收益率（= 折现率 r，时间的函数） + 超额收益率（来自"换了一个叙事"，与时间无关，瞬间完成）。

配套三定理：①只有改变叙事才有超额收益；②"股价涨幅≈业绩增速"是长周期视觉误差；③长牛股超额 = 几段叙事重估拼接，中间是"跟随大盘的垃圾时间"。

### 4.1 核心量化工具：PE 解析解 + 折现率反算

**公式**：预期 PE ≈ f(天花板高度 m, 折现率 r)，**与 n（到达天花板时间）无关**；只用"下一年业绩"做分母。

| 业绩预期 | 复合增速 | 合理动态 PE（r=7%） |
|---|---|---|
| 10年2倍 | 7.2% | 23.0 倍 |
| 5年2倍 | 14.9% | 23.1 倍 |
| 10年3倍 | 11.6% | 30.9 倍 |
| 5年3倍 | 24.6% | 30–31 倍 |
| 10年5倍 | 17.5% | 45.6 倍 |
| 5年5倍 | 38.0% | 45.2 倍 |

**折现率阈值（买卖点）**：**≥10% 安全**；**<10% 且行且珍惜**；**<8% 边打边撤**；成长股历史下限 7.4%（隆基 2015）；全股票历史下限 6.7%（长电 2024）。

### 4.2 大盘级叙事（识别 A 股整体起涨）

原文大盘直接论述较少，落地时用三个**宏观状态变量**逼近"整体起涨"：

1. **全A业绩兑现率**：`一致预期 vs 实际归母净利润`。2024 年全A实际=年初预期 79%（历史低位）；个股超年初预期 80% 即跑赢。→ **兑现率回升（宏观预期差收敛）是大盘起涨的隐含条件**（从"强预期弱现实"转向"预期可兑现"）。
2. **权益折现率**：无风险利率 ≠ 权益折现率（常负相关：无风险利率降→增长机会减→风险溢价升）。**识别市场整体折现率 r 的系统性下行**才是拔估值的根源。
3. **杠铃结构（终局）**：过去 24 个月全A收益-风险比呈 **S 型**——真正低风险公司收益不低、中风险既无胜率也无赔率。牛市末期"最没有梦想的公司反而涨最好"。

### 4.3 板块/ETF 级叙事（识别板块起涨）—— 三模板

| 模板 | 典型 | 起涨信号 | 加速 | 终点/证伪信号 |
|---|---|---|---|---|
| **A 龙头更替/王位交接** | 茅台 vs 五粮液 | 挑战者净利润**追平**龙头（2004） | 净利润**超过**龙头 | 挑战者价格标杆**追上**龙头（飞天批价追平普五） |
| **B 技术路线替代+政策一锤定音** | 光伏单晶 vs 多晶 | 市场提前发现替代趋势 | 政策文件（2017.7.18 能源局） | 替代比例兑现，3 个月涨完（空间 2.5 倍） |
| **C 低协方差资产重估** | 红利/长电 | 全A业绩兑现率大幅下降（熊市） | 利率下行+资产荒 | 缩圈至银行+股债利差<2pct |

**板块起涨通用机制**：板块行情 = 板块整体天花板相对宽基的变化；**持续时间取决于新叙事所需信号强度（越确定越快），涨幅取决于起点（原有叙事多低）**；**分歧才是上涨动力**。

**板块行情结束证伪信号（必须卖出）**：①**竞争格局恶化**（叙事向下）；②天花板代理变量趋势性下行；③龙头折现率反算过低；④与沪深300 走势重合（利空消化完成）。

### 4.4 核心判据：相对沪深300 重合度（可编程化）

> 原文最核心、可编程程度最高的判据：**"个股/板块 vs 沪深300 是否重合"——重合 = 叙事变化告一段落；偏离 = 正在发生叙事变化。**

**工程化改造**（把原文"事后肉眼"变"可计算"）：
- 滚动 N 月相对收益分位（如 3/6/12 月超额收益，偏离 >2σ = 叙事启动）；
- 滚动 beta 是否回落到 ≈1（回落 = 兑现完成）；
- 累计超额收益是否平台化（平台化 = 进入"垃圾时间"）。

### 4.5 补足原文缺口：叙事热度的事前指标（自建）

> 原文**没有**媒体词频/搜索指数类高频指标（只有事后"重合度+折现率反算+代理变量"）。为把"事后识别"变"事前捕捉起涨"，补足以下：

| 补足指标 | 已有数据 | 需自建 |
|---|---|---|
| 热度榜排名变化 | `alt_dc_hot.csv`（东财热股榜 rank）、`alt_ths_hot.csv`（同花顺热度 hot） | 无 |
| 涨停/连板情绪 | `alt_limit_cpt.csv`（up_nums/cons_nums） | 无 |
| 龙虎榜机构 vs 游资 | `alt_top_list_tushare.csv`、`alt_hm_detail.csv` | 无 |
| 研报提及频率 | `alt_report_rc_tushare.csv`（report_title/org_name） | 词频统计 |
| 新闻标题词频/搜索指数 | — | 需接入（百度指数/新闻 API） |

**词频二阶导法**：用"词频/搜索指数的增速加速度"逼近"叙事变化的一瞬间"（原文：预期差一经发现必被迅速消灭 → 词频增速拐点领先/同步于股价急涨）。

## 5. 量化评估体系（评分模型，输出"环境评分卡"）

### 5.1 底部评分卡（熊市底/牛市起点确认）

**核心规则（海通国际，硬阈值）**：五大类基本面领先指标中 **≥3 个企稳回升 = 底部确认**。

| 维度 | 指标 | 数据源 |
|---|---|---|
| ① 货币政策 | 各项贷款余额同比、M2 同比 | API/宏观 |
| ② 财政政策 | 基建投资累计同比 | API |
| ③ 制造业景气 | PMI、PMI 新订单 | `alt_macro_pmi.csv` |
| ④ 早周期-地产 | 商品房销售面积累计同比 | API |
| ⑤ 早周期-汽车 | 汽车销量累计同比 | API |

+ 补充：估值分位（PE 处于低分位）、风险溢价（≈均值+1σ）、情绪冰点（融资买入占比 <5% 分位）。**注意二次探底**（首底后需领先指标二次确认，否则"反弹后新低"失效，2012/12→2013/6、2022/4→2022/10 两次双底）。

### 5.2 顶部评分卡（牛市顶/转熊确认）

**无对称硬规则，用"估值极端 + 政策收紧 + 盈利见顶 + 情绪过热"组合打分**：

| 维度 | 信号 | 阈值 |
|---|---|---|
| 估值极端 | 全A PE(TTM) | **56–57 倍**（2007 顶）；或 PE/PB 处于近 10 年 90%+ 分位持续数月 |
| 风险溢价 | A股风险溢价 | 跌破均值 −1σ（性价比极低） |
| 政策收紧 | 升准/加息/查配资/资管新规/美联储加息 | 事件库触发 |
| 盈利见顶 | 全A盈利增速、主线 ROE 见顶回落 | 盈利顶→价格顶滞后 |
| 情绪过热 | 换手率、融资买入占比、涨停占比、新增开户、两融/流通市值 | 历史高位分位 |
| 结构分化反转 | 防御（必选消费/红利）由跑输转跑赢、主线放量滞涨 | 泡沫顶部领先信号 |

### 5.3 阶段定位状态机（投资时钟 7 阶段 → 1–7 编码）

`衰退前①(熊) → 衰退后②(牛起) → 复苏前③(牛) → 复苏后④(主升) → 过热⑤(牛末/顶) → 滞胀前⑥(转熊) → 滞胀后⑦(熊/出清)`

用 GDP/工业增加值（增长）+ CPI/PPI（通胀）+ 名义利率 + 实际利率打标，输出做多/规避区间。
