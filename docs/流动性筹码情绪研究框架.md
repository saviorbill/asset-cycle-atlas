# 指数与板块：流动性 / 筹码 / 情绪研究框架

> 目标：把「谁在买、用什么钱买、在什么成本上买」拆成可观测、可验证的三组指标，
> 用**分层状态**而不是一个总分来表达。

---

## 0. 一句话

价格告诉你结果，流动性告诉你有没有人参与，筹码告诉你谁被套住、谁还能卖，
情绪告诉你参与的人是贪婪还是恐惧。三者回答的是不同问题，**不能互相替代，也不该合成一个数**。

---

## 1. 先把三个词拆清楚

### 1.1 流动性：分三层，不能混用

| 层级 | 指标 | 回答什么 | 数据 |
|---|---|---|---|
| 宏观流动性 | M2、社融、DR007、10Y 国债、MLF/OMO 净投放 | 水池有多大 | `alt_macro_m2/sf`、`alt_lpr`、`alt_shibor` |
| 市场流动性 | 全A成交额、成交额/总市值、换手率、两融余额 | 水有没有流进来 | `market_daily`、`margin_full` |
| 资产流动性 | 个股/板块成交额、换手、量比、Amihud 非流动性 | 进出有多难 | `panel_csi_all_full`、`sw_daily` |

**常见错误**：把「成交额放大」直接叫「流动性好」。成交额放大也可能是恐慌抛售，
所以成交额要和换手率、价差、两融一起看。

### 1.2 筹码：回答「谁被套、谁还能卖」

| 指标 | 含义 | 数据 |
|---|---|---|
| 获利盘比例 `winner_rate` | 当前价高于持仓成本的市值占比 | `alt_cyq_perf_tushare.csv` |
| 成本分布 5/15/50/85/95 分位 | 筹码集中在哪些价位 | 同上 |
| 套牢盘比例 | 当前价低于成本 50 分位的部分 | 由成本分位推算 |
| 集中度 | 股东户数、前十大持仓、机构持仓 | 需补（见 §7） |
| 杠杆筹码 | 两融余额 / 流通市值 | `margin_full` |

筹码的关键是**成本结构**：上方套牢盘厚，反弹就有人卖；下方获利盘厚，回调就有支撑。

### 1.3 情绪：回答「有多热 / 多冷」

| 子类 | 指标 | 数据 |
|---|---|---|
| 交易情绪 | 融资买入占比、涨跌停家数、封板率、连板高度 | `margin_full`、`limit_daily` |
| 衍生品情绪 | 50ETF/300ETF 隐含波动率、VIX | `iv_index.parquet`、VIX |
| 资金情绪 | ETF 份额变化、国家队净申购、龙虎榜净买 | `fund_share`、`nsf_flow`、`top_list` |
| 注意力情绪 | 热搜、东财热股、分析师上调比例 | `alt_ths_hot`、`alt_dc_hot`、`report_rc` |

## 3. 标准化：双分位，而不是单一 z-score

每个指标同时算两个分位：

1. **纵向分位**：在自身滚动 5 年历史中的位置（0–100）
2. **横向分位**：同一天 31 个板块之间的排名（0–100）

两者交叉成四象限：

| | 横向高 | 横向低 |
|---|---|---|
| **纵向高** | 主线（自己历史极端 + 全市场最强） | 独立行情（自己极端但市场没跟上） |
| **纵向低** | 补涨候选（市场强但自己不极端） | 冷门（双低） |

这个二维图比任何合成分都更有信息量，也避免了「权重怎么定」的问题。

## 4. 组合方式：三层输出，不合成总分

### 第一层：状态标签
每个资产给出一个三字标签，例如：

- 流动性：宽 / 平 / 紧
- 筹码：轻 / 中 / 重（上方套牢盘）
- 情绪：热 / 温 / 冷

组合成「宽-重-冷」这样的状态码。读者一眼能定位，不需要理解分数。

### 第二层：极端预警
任一维度进入 <5% 或 >95% 分位时提示，并给出历史上同样极端后的收益分布。

### 第三层：条件分布
给定当前状态码，统计历史上相同状态之后 20/60 日的收益分布（中位、p10、p90、样本段数）。
**这是唯一可以直接用于决策的产出**，其余都是描述。

## 5. 怎么验证

| 方法 | 做什么 | 注意 |
|---|---|---|
| 事件研究 | 指标进入极端后，未来 20/60 日收益分布 | 要报告独立片段数，不是天数 |
| 前瞻台账 | 每天记录状态码与建议，T+1 起算 | 已在做（`recommendations.csv`） |
| 分组单调性 | 按指标五分位分组，看收益是否单调 | 不单调说明该指标无效 |
| 多重检验 | 31 板块 × 4 指标 × 3 期限 = 372 个组合 | 必须做 FDR 校正，否则全是假阳性 |

**缺，但可以补**

| 缺口 | 影响 | 补法 |
|---|---|---|
| 股东户数 | 筹码集中度缺一块 | Tushare `stk_holdernumber`，季度更新 |

| 逐笔 / Level2 | 无法算真实冲击成本 | 成本高，暂不做 |
| 北向日度 | 已停（2024-08） | 用港股通持股变化代替 |

## 8. 三个容易踩的坑

1. **成交额既是流动性也是情绪**。同一个数放进两个维度，会人为放大它的权重。
   流动性用「成交额/市值」，情绪用「融资买入占比、涨跌停比」，不要重复。
2. **分位窗口的选择会改变结论**。5 年 vs 全历史，在 2008 和 2015 之后差别巨大。
   建议固定 5 年，并在图注里写明。
3. **筹码数据是模型估算，不是真实持仓**。`cyq_perf` 基于成交量和换手率反推，
   在长期停牌、大宗交易多的股票上会失真。用它做横截面排序可以，做精确点位不行。
