# 部署到腾讯云 CloudBase（免费 · 国内节点 · 免备案）

CloudBase（云开发）静态网站托管：**国内 CDN 节点、默认域名免备案、无 VPN 可秒开**。
免费额度：**存储 5GB + CDN 流量 5GB/月**。

---

## 一、开通（约 10 分钟）

1. 打开 <https://console.cloud.tencent.com/tcb> 登录（微信/QQ 扫码即可）
2. 首次使用需**实名认证**（个人身份证，几分钟）
3. **创建环境**：
   - 环境名称：`asset-cycle-atlas`
   - 计费方式：选 **按量计费**（有免费额度）
   - 地域：**上海**（国内节点）
4. 创建后进入环境 → 左侧 **静态网站托管** → **开通**（免费）
5. 记下你的**环境 ID**（形如 `app-xxxxxxxx`，在环境概览页）

---

## 二、上传网站（二选一）

### 方式 A：控制台拖拽（最简单）

1. 进入 **静态网站托管** → **文件管理**
2. 把本地 `web/` 目录里的**所有文件和子目录**拖进去（index.html 要放在根目录）
3. 等待上传完成

### 方式 B：命令行（推荐，以后一条命令更新）

```bash
cd ashare-fupan
./deploy-cloudbase.sh app-你的环境ID
```

首次会要求登录（浏览器授权）。

---

## 三、访问

你的站点地址：

```
https://<环境ID>.tcloudbaseapp.com/
```

例如 `https://app-1a2b3c45.tcloudbaseapp.com/`

> **国内直接打开，不需要 VPN**，走腾讯云 CDN。

---

## 四、以后如何更新

```bash
# 改完代码/数据后
cd ashare-fupan
./deploy-cloudbase.sh app-你的环境ID
```

或控制台 → 静态网站托管 → 文件管理 → 覆盖上传改动的文件（`web/data*.js` 等）。

---

## 五、注意事项（重要）

1. **默认域名的限制**（2025-10-09 后新环境）：
   - 有**访问频率风控**，正常浏览没问题
   - 偶尔可能出现**访问提醒中间页**（点继续即可）——这是腾讯云合规要求
   - 不要用脚本高频刷同一域名
2. **免费额度**：存储 5GB、CDN 流量 5GB/月。
   - 你的站点约 13MB；因为浏览器有缓存，**重复访问只下载约 200KB**
   - 5GB/月 ≈ 2-3 万次正常访问，个人使用完全够
3. **HTTPS**：默认域名自带 HTTPS，无需配置证书
4. **自定义域名**：如果以后想用 `fupan.你的域名.com`，绑定自定义域名**需要备案**（和免备案的默认域名不同）

---

## 六、与 GitHub Pages 的关系

- 两边可以**同时存在**：GitHub Pages 作为开源展示，CloudBase 作为国内正式访问
- 代码只维护一份（GitHub），CloudBase 只是把 `web/` 目录同步上去

---

## 附：命令行一次配置（可选）

如果不想每次敲环境 ID，可以设置：

```bash
npx @cloudbase/cli login
npx @cloudbase/cli env:list        # 查看环境 ID
```

然后在项目根目录每次执行 `./deploy-cloudbase.sh <环境ID>` 即可。
