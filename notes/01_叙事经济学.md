# 01 叙事经济学：寻找A股投资解析解 —— 量化框架提炼笔记

> 来源：华源证券《宏观研究·叙事经济学：寻找A股投资解析解》（邹佩轩，SAC:S1350524070004，2026-10-20）
> 用途：为「用叙事经济学识别 A股整体起涨 与 板块/ETF 起涨」的量化框架服务。
> 说明：本文是"提炼后的方法论 + 可量化信号 + 阈值/案例"，不保留原文叙述性文字；凡引用原文口径的，均标注【原文口径】。

## 0. 一句话核心主张（作者的中心论点）

> **超额收益只在"叙事发生变化的一瞬间"完成，与业绩增速无关；兑现叙事不产生任何超额收益，无论增速多高。**
>
> 股价 = EPS × PE，但股价涨幅**不能**拆分为"业绩增长 + 估值变化"。正确拆分是：
> - 第一部分 = 必要收益率（= 折现率 r，是"叙事的机会成本"，时间的函数）；
> - 第二部分 = 超额收益率（来自"换了一个叙事"，与时间无关，往往在很短时间内完成）。

配套三定理：
1. **只有改变叙事才会有超额收益**，股价在很短时间内涨完；漫长的兑现叙事不产生波澜（哪怕业绩5倍）。
2. **股价涨幅≈业绩增速只是长周期视觉效果**，是错误归因；真实节奏完全不同。
3. **长牛股的超额收益是几段"叙事重估"拼起来的**，每段之间是"跟随大盘波动的垃圾时间"。

## 1. 叙事经济学的核心定义与机理

### 1.1 定义（原文提炼）
- **叙事 = 市场对一家公司/一个板块"目之所及的所有未来"的集体共识**。当前时点的"未来"并未发生，它本质是一段叙事（预期），股价是这段叙事的折现。
- **PE 的底层逻辑是"空间叙事"**：估值不取决于增速，取决于**天花板高度（空间）**和**折现率（信念成本）**。

### 1.2 机理：PE 的"解析解"（本文最核心的数学结论）

DCF 简化模型假设：当前利润=1，业绩天花板=m 倍，n 年匀速增长到天花板后永续不变，折现率=r，权益现金流=净利润。

【原文口径】结论：
1. **预期 PE 几乎只与天花板高度 m 和折现率 r 有关，与 n（多久到达天花板）无关**——"1/n 和 n 形成对冲"。
2. **只能用"下一年的业绩"做分母计算动态 PE**，n 的影响才被对冲掉（用当年或下两年业绩都没有这个效果）。
3. "这就是信仰的力量：**只要相信，无惧遥远**。"

【原文口径】折现率取 7% 时的测算对照表：

| 业绩预期 | 复合增速 | 合理动态PE |
|---|---|---|
| 10年2倍 | 7.2% | **23.0倍** |
| 5年2倍 | 14.9% | **23.1倍** |
| 10年3倍 | 11.6% | **30.9倍** |
| 5年3倍 | 24.6% | **30.0~31.0倍**（原文两处口径，见下注） |
| 10年5倍 | 17.5% | **45.6倍** |
| 5年5倍 | 38.0% | **45.2倍** |

> 注：原文第5页文字写"5年3倍对应 PE 30.0倍"，第7页表格写"5年3倍合理动态PE 31.0倍"，属原文自身四舍五入/表格精度差异，量化时取 **≈30~31倍** 即可。

推论（原文）：
- **PEG/景气度投资既是陷阱又耽误赚钱**：增速高常与空间大共存，但无必然联系。
- 反例：业绩预期从"10年5倍"下修到"5年3倍"时，PE 从 45.6 降到 31.0，但未来5年复合增速反而从 17.5% 升到 24.6%——**按 PEG 会做出"应该抄底"的错误决策**（A股行业下行期常犯的错误）。
- 经典困惑解释：很多公司进入业绩爆发期后股价反而跌——爆发前有"朦胧美"、天花板被拍高；爆发后天花板能算清，市场一次性上修/下修。

### 1.3 叙事如何影响预期、价格、资金行为
- **预期**：叙事决定"天花板高度 m"与"折现率 r"两个唯一参数；业绩只负责"兑现叙事、保障股价不跌"，不负责"让股价涨"。
- **价格**：叙事一变，股价在极短时间内跳变完成重估；之后回归"跟随宽基指数"。
- **资金行为**：机构"既不能蹲、也不能先信"；预期差一经发现必然被迅速消灭（市场越来越卷）；A股**向上定价能力远强于向下定价能力**，多空反应速度不对等（利好打提前量快、利空消化慢）。

## 2. 叙事的完整生命周期（原文可推导的循环 + 识别信号）

### 2.1 核心循环模型（原文明确表述）
```
兑现叙事(无超额收益) → 改变叙事(超额收益,可正可负) → 兑现叙事(无超额收益) → ……
```
- 原文用词对照：**兑现叙事 / 改变叙事（向上） / 改变叙事（向下）**。
- **新叙事形成后往往不会立即修正，而是会观察一段时间（可能长达数年）**——即"叙事"是低频、台阶式跳变，不是连续变量。

### 2.2 各阶段特征与识别信号（原文可提炼的判定表）

| 阶段 | 特征 | 识别信号（原文口径） |
|---|---|---|
| **诞生/起涨** | 天花板高度 m 上修，或折现率 r 下修 | ①个股/板块相对沪深300开始**持续偏离（跑赢）**；②重大供需格局信号、关键技术突破、改变竞争格局/打开空间的政策文件出现 |
| **传播/共识** | 资金迅速消灭预期差，股价急涨 | 个股相对沪深300超额收益在极短时间内走完（如3个月、4个月、9个月、1年） |
| **主导/高潮** | 预期打到"能自圆其说的上限" | 折现率反算跌破安全阈值（见 §7）；天花板代理变量（如批价/出厂价）见顶 |
| **兑现期/垃圾时间** | 业绩兑现但无超额收益 | **个股走势与沪深300重合**（这是本文最核心的判据） |
| **证伪/衰退（向下改变叙事）** | 天花板下修或壁垒被破坏 | ①竞争格局恶化（**必须卖掉**）；②天花板代理变量趋势性下行；③折现率反算过高（天花板被证伪） |
| **极端化/泡沫** | 折现率过低 | 折现率反算 <8%（边打边撤）、<6.7%（全股票历史下限） |

### 2.3 关键洞察
- **"个股 vs 沪深300 是否重合"是全文贯穿的**、可编程程度最高的**事后叙事识别器**：重合=叙事变化告一段落；偏离=正在发生叙事变化。
- **利空方与利好方的"叙事进度条"不一样**：同一时间点，上下游对不上（如"煤价跌4年 vs 煤炭跑输2年半 vs 煤电跑赢9个月"）。
- **天花板轻易不会上修**，只能来自三类信号：①重大供需格局变化；②关键技术突破；③改变竞争格局/打开市场空间的**政策**。业绩释放不会上修天花板（煤炭黄金12年都没上修）。

## 3. 识别/测量"叙事"的可量化指标（凡原文提到的全部列出，标注原文口径）

> **重要澄清（必读）**：原文**并未使用**"媒体词频、搜索指数、研报提及、成交集中度"这类常见的叙事热度高频指标——这些是任务假设中预想的指标，但原文没有给出。原文采用的是**另一套"估值-相对走势-代理变量"方法论**。二者要在落地时区分开（见 §8 补充建议）。

原文实际提供的、可量化的代理变量/信号如下：

| # | 指标/代理变量 | 原文口径 | 用途（识别什么） |
|---|---|---|---|
| 1 | **个股/板块相对沪深300的走势重合度** | "如果两者重合了，可以认为叙事变化告一段落" | 识别叙事是否已兑现、是否发生新变化（事后） |
| 2 | **折现率 r 反算** | 给定天花板 m 与当前动态PE，反算隐含折现率 | 判断叙事"极端化"程度/买卖点 |
| 3 | **天花板高度代理变量**（白酒）= 批价/出厂价倍数 | "茅台预期PE/沪深300预期PE 与 批价/出厂价 两条曲线高度一致" | 事前代理天花板相对高度变化 |
| 4 | **茅台净利润 vs 五粮液净利润 的排名** | 追平=起点；超过=加速 | 识别龙头更替叙事（王位交接）的起涨点 |
| 5 | **飞天批价 vs 普五批价 的交叉** | 飞天批价追上普五 = 叙事结束 | 识别叙事终点的信号 |
| 6 | **政策文件/事件时点** | 2017.7.18能源局发文、2018.5.31"531"新政、2011.12电价上调、2020.9双碳、2020.3欧盟气候法 | 识别叙事变化的**催化**（定性触发） |
| 7 | **行业路线图/渗透率展望 vs 实际** | 工信部《中国光伏行业发展路线图(2016年版)》单晶份额2025年才48% vs 实际 | 识别"市场预期 vs 权威展望"的预期差 |
| 8 | **全A业绩兑现率** | wind一致预期 vs 实际：2024年=79%（历史低位） | 识别全市场风险偏好/风格（红利超额收益之源） |
| 9 | **A/H 价差/两地叙事收敛** | 兖矿A股2003年反映、港股2004年底（电荒催化） | 识别同一资产两地叙事进度差 |
| 10 | **收益-风险比散点（S曲线）** | 年化收益率 vs 月度收益率标准差再年化 | 识别"杠铃两端 vs 中间"的赔率胜率分布 |
| 11 | **基本面与宏观经济的协方差**（CAPM β） | 协方差足够小才能受益于无风险利率下降 | 识别红利/低波资产的叙事变化之源 |

> 结论：原文的"叙事测量"本质是**"相对基准的超额收益形态 + 折现率反算 + 行业特定天花板代理变量"**，而非舆情/词频类指标。量化落地需自建词频/搜索类指标来补充其"事前性"。

## 4. 叙事如何作用于"A股整体（大盘）起涨"

原文对**大盘指数层面**的直接论述**较少且偏宏观机制**，主要结论如下（需结合个股/板块机制外推）：

1. **全A业绩兑现率决定风险偏好与市场风格**（§7.2）：
   - 2021下半年起"强预期、弱现实"愈发突出；年初高开、逐季下修、最终又低于下修后预期。
   - 【原文口径】2024年全A实际归母净利润=年初预期的 **79%**，历史低位；**个股只要最终业绩超过年初预期的八成（80%）就能跑赢市场**。
   - 这是近年来红利资产跑出超额收益的根本原因——不是红利涨得好，而是"这才是一个股票正常的走势"。
   - → **大盘起涨的隐含条件：全A业绩兑现率回升（宏观预期差收敛）**，市场从"强预期弱现实"转向"预期可兑现"。

2. **权益折现率与无风险利率非单调**（§7.4）：无风险利率下降≠权益折现率下降，常负相关（风险溢价内生：无风险利率降=增长机会减少=风险溢价上升）。故不能简单用国债利率推大盘估值。

3. **协方差是叙事变化之源**（§7.5）：经济转型期，业绩受宏观影响小、能穿越周期的公司获得估值提升（不需要天花板打开）。

4. **杠铃策略是A股机制演化的必然**（§7.6，可视为"大盘级叙事演化终局"）：
   - A股向上定价能力远强于向下 → 展望期预期打到"能自圆其说的上限"而非"最可能情况"。
   - 兑现期"最没有梦想"的公司反而涨最好。
   - 【原文口径】过去24个月全A收益-风险比非单调，呈**S型曲线**：超高收益（年化>50%）伴随高风险；**真正低风险公司预期收益率并不低**；**中风险公司既没胜率也没赔率**（杠铃中间）。

> **对量化框架的直接启示**：识别"大盘起涨"，本质是识别**市场整体折现率 r 的系统性变化 + 全A业绩兑现率拐点**，而非单一业绩增速。原文未给出大盘指数的"叙事生命周期"阶段判定标准，需自行补齐（见 §8）。

## 5. 叙事如何作用于"板块/ETF 起涨"

原文的板块级结论丰富，是落地 ETF 信号的核心素材。

### 5.1 板块起涨的通用机制（原文结论）
1. **板块共识行情 = 板块整体天花板高度的相对变化（相对宽基）**，而非业绩增速。
2. **板块行情持续时间取决于"形成新叙事所需信号的强度"，产业链趋势越确定、持续时间越短；涨幅取决于涨之前的起点（原有叙事有多低）**——【原文口径：复盘历史涨幅与持续时间没有意义】。
3. **分歧才是上涨的动力，没有分歧就不会有叙事变化**（单晶 vs 多晶案例）。
4. **政策导向可改变叙事比例**：光伏案例中，政策发布前市场对单晶叙事=替代40%，发布后=彻底取代，**空间提升2.5倍，3个月结束战斗**。

### 5.2 "板块共识行情如何形成"（原文给的三个典型模板）

**模板A：龙头更替/王位交接（白酒）**
- 起点信号：龙二/挑战者净利润**追平**龙头（茅台追平五粮液，2004年）。
- 加速信号：挑战者净利润**超过**龙头。
- 终点信号：挑战者的**价格标杆**（飞天批价）**追上**龙头标杆（普五批价）。
- 底层护城河 = 无形之物（辨识度、迁移成本），"一个时代只能有一个王"。

**模板B：技术路线替代 + 政策一锤定音（光伏单晶 vs 多晶）**
- 起涨：2014年底市场提前发现单晶替代趋势（成本决定战役实际2016下半年才发生，资本市场打2年提前量）。
- 加速：2017.7.18 能源局发文（转换效率门槛偏袒单晶）。
- 终点：3个月涨完，后续业绩与股价无关。

**模板C：逆周期/低协方差资产重估（红利/长江电力）**
- 触发：全A业绩兑现率大幅下降时（2015下半年、2018、2022-2024），低波资产"叙事变化恰好发生在熊市"。
- 本质：红利超额收益 = 它"跟随指数不跌"，而非"涨得多"。

### 5.3 "板块行情如何结束"（原文给的证伪信号）
1. **竞争格局恶化 → 必须卖掉**（原文："在竞争格局出问题的时候一定要卖掉，因为叙事发生了向下的变化"）。光伏双碳行情没走到最后的原因不是量，而是**壁垒缺失→量的空间无法转化为利润的空间**。
2. **天花板代理变量趋势性下行**：茅台批价/出厂价比值下降 → 板块跑输。
3. **龙头折现率反算过低（天花板被拍太高）**。
4. **利空消化完成 = 与宽基重合**：煤炭兖矿能源利空用2年半才消化完（2014.6后与沪深300重合），期间持续跑输——**A股对利空反应慢、对利好反应快**。

### 5.4 ETF落地建议（提炼）
- 对**可算清天花板的行业**（政策驱动的光伏、量价可测的资源品）：用"折现率反算 + 政策事件触发"。
- 对**算不清天花板的行业**（消费、平台）：用"天花板代理变量（批价/价差）+ 龙头更替排名信号"。
- 通用 ETF 层信号：**板块指数 vs 沪深300 的滚动超额收益形态**（重合=行情结束，偏离=叙事启动）。

## 7. 可直接转化为量化规则的结论（原样保留数字）

### 7.1 PE 解析解规则（§1.2）
- 预期 PE ≈ f(天花板高度 m, 折现率 r)，**与 n（到达时间）无关**；只用"下一年业绩"做分母。
- 7% 折现率基准：2倍→23倍，3倍→30~31倍，5倍→45~46倍（见 §1.2 表）。
- **天花板 m 下修但增速上修时，业绩增长弥补不了估值下跌**（PEG陷阱）。

### 7.2 折现率阈值（§3.3，原文原文）
- **A股折现率大部分时间 10% 较为合理**。
- **隆基 2015 牛市最高点反算折现率 7.4%** = 成长股下限。
- **长江电力 2024年7月反算 6.7%** = 所有股票的折现率下限。
- 【§5.2 安全区间】折现率 **≥10% 安全**；**<10% 且行且珍惜**；**<8% 边打边撤**。

### 7.3 板块/个股操作规则
- **"个股 vs 沪深300 重合 = 叙事变化告一段落"**——新叙事形成后观察期可能长达数年。
- **竞争格局出问题 → 必须卖掉**（叙事向下）。
- **一两次业绩低于预期别慌；竞争格局出问题才卖**（§2.5）。
- **便宜不是上涨理由，需要重大事件改变叙事导致两地/两资产叙事收敛**（兖矿A/H）。

### 7.4 茅台特化规则（可直接写进策略的范式）
- 起涨：**净利润追平龙头**；加速：**净利润超过龙头**；结束：**价格标杆追上龙头**（2004-2006）。
- **批价/出厂价比值上升 → 股价有超额收益（天花板上修）**；
- **批价不变、提出厂价 → 只消化估值、无超额收益**；
- **批价下降 → 天花板下修 → 跑输市场**；
- 批价是"经济发展模式的缩影"，市场对批价难有提前预期，**需持续跟踪**。

### 7.5 全A/大盘规则
- 【§7.2】2024 全A实际业绩/年初预期 = **79%**；个股**超年初预期80%即跑赢市场**。
- 【§7.6】过去24个月全A收益-风险比呈**S型**：年化收益>50%必伴随高风险；低风险公司收益不低；中风险无胜率无赔率。
- 【§4.4】华能国际第二轮超额收益**4个月 +50%**；兖矿利空跑输**2年半**；煤电逆周期属性满打满算**9个月**——印证"利好快、利空慢"。

### 7.6 操作心法规则
- **沙盘推演 + 信号触发，反对"福尔摩斯推票法"**（链条一长，市场不按剧本走）。
- 先算每种可能性对应的**股价绝对点位**，跟踪"决定历史走向的信号"，信号出现下手要快。
- **超额收益靠少犯错误，不是极致正确**（霍华德·马克斯）。

## 8. 落地时的数据缺口 + 原文未讲清之处（补充建议）

### 8.1 原文未讲清 / 未覆盖的关键盲点
1. **没有"事前、实时"的叙事热度指标**：原文全程用"相对沪深300重合度""折现率反算""批价代理变量"这套**事后/低频**方法，**没有给出媒体词频、搜索指数、研报提及、成交集中度、换手率等事前高频热度指标**。要识别"起涨"（而非"已涨完"），必须自行补这类指标。
2. **"叙事变化的一瞬间"如何事前捕捉**：原文强调沙盘推演+信号跟踪，但信号是**定性**的（政策文件、技术突破、供需格局），**没有给出可编程的触发规则/阈值**。
3. **折现率 r 的估计依赖天花板 m**，而原文承认很多行业"算不出天花板绝对值"，只能用代理变量——**代理变量的选取没有通用方法论**（茅台批价是特例，其他行业对应物不明）。
4. **"个股/板块 vs 沪深300 重合"没有量化定义**：原文用肉眼判断重合/偏离，**未给出统计口径**（滚动超额收益、滚动 beta、相关系数、累计超额阈值等均未定义）。
5. **大盘（指数）层叙事识别几乎空白**：原文只有个股+板块案例，对"整体起涨"只给了宏观机制（业绩兑现率、折现率、杠铃），**没有指数级叙事生命周期阶段判定**。
6. **频率问题**：原文是月度/事件驱动复盘，量化落地需日频/周频信号。
